Get started

Two ways to run it.

Desktop app

  1. Download the app.
  2. Run it.
  3. Write your first note.
Download

macOS: The app isn't signed by Apple yet. The first time, open System Settings > Privacy & Security and click Open Anyway next to Jacarium.

Linux: Make the AppImage executable (chmod +x) and run it, or install the package: sudo apt install ./jacarium_*.deb (Debian, Ubuntu) or sudo dnf install ./jacarium-*.rpm (Fedora, RHEL). Needs a recent distribution: Ubuntu 24.04, Debian 13, Fedora 40, RHEL 10 or newer.

Self-hosted

  1. Run the container on your server, such as a Raspberry Pi.
  2. Open it in your web browser.
  3. Write your first note.
Container image

Image: quay.io/zerodayz/jacarium (amd64 and arm64, e.g. a Raspberry Pi 4/5 with a 64-bit OS).

Quick start

mkdir -p ~/.config/jacarium/server/data

IP=$(hostname -I | awk '{print $1}')

podman run -d --name jacarium --hostname jacarium --restart unless-stopped -p "$IP:8443:8443" -e TLS_SAN="IP:$IP" -v ~/.config/jacarium/server/data:/data:Z,U quay.io/zerodayz/jacarium:latest

# Get the one-time setup code for the first account
podman logs jacarium

This machine only: use -p 127.0.0.1:8443:8443 and drop TLS_SAN.

Then open https://<IP>:8443 (echo $IP shows the address) and create the first account with the setup code. The certificate is self-signed, so your browser warns once.

Privacy and data

Your notes stay on your infrastructure.

Jacarium is offline by default.

Where your data lives
In your browser first. With Home Server on Raspberry Pi.
What we collect
Nothing.
Export and backups
Export to Markdown, ZIP, JSON or PDF at any time.

Important

  • For access away from home, connect to your home server through your own VPN.
  • Traffic is encrypted, but stored data isn't, so use disk encryption such as FileVault or LUKS.
  • You run and secure it yourself, without warranty under the AGPL-3.0 licence.
