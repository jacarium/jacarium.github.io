Backups and updates

How to take a backup? (Desktop)

Export your database from Application Settings › General › Database › Export Database.

How to take a backup? (Self-Hosted)

Everything is in the data folder, ~/.config/jacarium/server/data. Stop the container, archive the folder and start it again:

podman stop jacarium

podman run --rm --volumes-from jacarium --entrypoint tar quay.io/zerodayz/jacarium:latest czf - -C / data > ~/jacarium-backup-$(date +%F).tar.gz

podman start jacarium

The backup is saved in your home folder, for example ~/jacarium-backup-2026-10-16.tar.gz. With Docker, use docker instead of podman.

How to update to the latest version? (Desktop)

Before you update, take a backup, just in case.

Quit Jacarium and download the new version from the latest release, then:

  • macOS: open the .dmg, drag Jacarium to Applications and choose Replace.
  • AppImage: replace the old file with the new one, then chmod +x Jacarium-*.AppImage.
  • .deb: sudo apt install ./jacarium_<version>_amd64.deb (or _arm64).
  • .rpm: sudo dnf install ./jacarium-<version>.x86_64.rpm (or .aarch64).

Your documents and settings stay where they are.

How to update to the latest version? (Self-Hosted)

Before you update, take a backup, just in case.

Pull the new image and recreate the container with the same command as the first time. Your data stays in ~/.config/jacarium/server/data.

podman pull quay.io/zerodayz/jacarium:latest

podman rm -f jacarium

IP=$(hostname -I | awk '{print $1}')

podman run -d --name jacarium --hostname jacarium --restart unless-stopped -p "$IP:8443:8443" -e TLS_SAN="IP:$IP" -v ~/.config/jacarium/server/data:/data:Z,U quay.io/zerodayz/jacarium:latest

docker works the same way. To stay on one version, use its tag instead of :latest. See what's new.

Self-hosting

Why can't I reach Jacarium by its IP address?

curl -kL https://192.168.1.20:8443 doesn't work and is unreachable, but curl -kL https://127.0.0.1:8443 does.

The quick start listens only on 127.0.0.1 on purpose: the idea is to put Caddy in front of it as a reverse proxy.

To reach Jacarium directly by IP instead, use the solution below.

Solution, replacing 192.168.1.20 with your server's IP:

podman rm -f jacarium

rm -f ~/.config/jacarium/server/data/certs/cert.pem ~/.config/jacarium/server/data/certs/key.pem

podman run -d --name jacarium --hostname jacarium --restart unless-stopped -p 192.168.1.20:8443:8443 -e TLS_SAN="IP:192.168.1.20" -v ~/.config/jacarium/server/data:/data:Z,U quay.io/zerodayz/jacarium:latest
